# نبض فارکس — نسخه وب عمومی

این مخزن نسخه وب اپلیکیشن «نبض فارکس» است که روی GitHub Pages میزبانی می‌شود:

**آدرس سایت:** https://mrbot7241-cyber.github.io/nabz-forex/

## چطور کار می‌کند؟

- سایت کاملاً **بدون سرور** است: معاملات روی مرورگر خودتان (localStorage) ذخیره می‌شوند.
- قیمت‌ها (دلار، یورو، طلای ۱۸) از منبع معتبر **TGJU** استخراج و در فایل `data/prices.json` ذخیره می‌شوند.
- یک GitHub Action هر **۱۵ دقیقه** این فایل را به‌روزرسانی می‌کند و سایت خودکار تازه می‌شود.
- نرخ‌های جهانی از open.er-api.com و تقویم اقتصادی از ForexFactory گرفته می‌شود.

## فایل‌های مهم

| مسیر | توضیح |
| --- | --- |
| `index.html` + `assets/` | نسخه ساخته‌شده اپ (Vite) |
| `data/prices.json` | اسنپ‌شات قیمت‌ها و تقویم اقتصادی |
| `scripts/update_prices.py` | اسکریپت به‌روزرسانی داده‌ها |
| `.github/workflows/update-prices.yml` | زمان‌بند اجرای هر ۱۵ دقیقه |
